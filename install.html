安装

Chrome

正式方式：Chrome 网上应用店搜索 buusdo Cybersecurity Service Tool → 添加到 Chrome。商店链接上架后会写在产品配置里；未上架前请使用开发者提供的安装包说明。

扩展默认连接 https://buusdocst.mtsu.workers.dev 。若本机访问 Workers 超时，会显示专用提示，不代表扩展损坏。

Safari 扩展

Safari（macOS）

正式方式：Mac App Store 安装 buusdo Cybersecurity Service Tool 包装应用 → Safari → 设置 → 扩展 → 启用。

桌面应用（GitHub，未签名）

正式桌面包在 GitHub Releases 下载（Windows / macOS zip / Linux deb；mac zip 约 ~58 MB）。当前未做公证 / 代码签名：macOS 首次打开可能被 闸门守护（Gatekeeper）拦截，Windows 可能出现 SmartScreen「未知发布者」——属预期。步骤与 Workers 站点设置同一指南： 安装指南（未签名） （与 Workers 设置 → 安装指南相同）。
